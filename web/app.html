Milestone Oracle

A public, challengeable checklist for one delivery milestone, running as a GenLayer Intelligent Contract on Studionet. It holds no funds: a finalized verdict is an attestation anyone can read.

Wallet

Not connected.

Every transaction is signed in your own wallet (MetaMask or any EIP-1193 wallet) on the GenLayer Studio network. This page never asks for, creates or stores a private key. Use a Studio test account, not one that holds real funds.

Contract

Create a milestone (deploys a new contract)

The connected account becomes the funder. The builder is a different account. Contract code is fetched from this repository (../contracts/milestone_oracle.py) and sent as a deploy transaction you sign.
